# Playroom 玩点 · V1.7

中文小游戏网站，使用原生 HTML、CSS、JavaScript，无构建步骤。九款游戏均在本站运行。三款 3D 游戏使用随网站托管的 Three.js，不嵌入外部游戏服务。

## 包含

- 下坠小球：无限生成的立体圆环塔；拖动或左右键旋转圆环，小球自动弹跳，寻找缺口下落并避开带条纹的红色区域。连续下坠 3 层激活 1.35 秒破障；连落倍率与最高分；始终保留前方圆盘，回收旧圆盘和模型，长时间游戏保持固定内存窗口。云层保留世界坐标，镜头下降时自然经过，只在离开视野后循环回收。
- 黑洞吞城：自由移动的限时吞噬游戏；不规则海岛上的城市物体，包括路锥、垃圾桶、树、汽车、房屋、高楼和中心大厦。吞噬获得体积，只能吞下尺寸合适的物体；连吞最高 5 倍，每 15 件加 5 秒，1.1 秒疾行与 6 秒冷却。支持键盘、点击目标和拖动地图。相机以黑洞为中心近距离跟随，随半径平滑扩大视野；不规则岛岸、沙滩与同一岸线约束的陆地移动。海水使用顶点波浪、解析法线、细波纹、镜面高光和近岸泡沫，暂停时冻结。
- 城市模型：阔叶树、分层松树和棕榈随机分布；车辆增加玻璃、轮毂、车灯、后视镜和保险杠；建筑增加独立窗格、窗台、门厅、屋顶设备和不同屋顶；街边物件增加轮子、开口和细节。共享模型模板按材质合并网格，避免逐个细节产生过多绘制调用。
- 城市内加入 22 个会活动的小人，具有摆臂、迈腿、朝向和跑动起伏；靠近黑洞时加速逃跑，避让建筑并保持在陆地，吞噬获得积分和体积。暂停冻结移动与动画。
- 新游戏支持暂停冻结物理与计时、重开、窗口放大、当前浏览器最高分保存。事件与进度显示在画面下方。

- 公路穿行：三车道驾驶、刹车与逐步增加的车流，每组障碍保留通道。
- 护盾：道路拾取后免伤 8 秒；氮气：消耗 60 能量冲刺 3.5 秒，期间免伤并撞翻车辆，连撞最高 5 倍。
- 金币、10 秒磁铁、10 秒双倍积分、补充氮气与修理道具。
- 三格耐久、碰撞保护、险超奖励、局内任务与完成奖励。
- 每 800 米切换城市、沙漠、霓虹夜景，使用相应场景模型、配色和灯光。
- 可见的道具倒计时、耐久、氮气进度、金币与任务进度；暂停冻结计时。任务和临时事件使用道路下方的固定状态栏，限时道具不重复弹窗。
- 窗口放大与还原、统一暂停和重开、键盘/触控按钮/拖动换道。

- 2048：方向键、WASD、滑动与屏幕按钮；分数和最佳成绩。
- 贪吃蛇：果实、加速、边界与身体碰撞、暂停和重开。
- 打砖块：鼠标、触控、键盘挡板；三次机会、关卡与计分。
- 扫雷：9×9、10 颗地雷、首点周边安全、右键/按钮标记和计时。
- 记忆翻牌：8 对卡片、翻牌动画、步数和通关结算。
- 井字棋：Minimax 电脑对手及同设备双人模式。
- 分类、搜索、随机游戏、收藏、深浅色切换。
- 响应式布局，支持减少动画的系统偏好。
- 鼠标悬停游戏封面时，图形在 0.6 秒内轻微倾斜、抬升并呈现各游戏的局部动作；移开后平滑复位。键盘聚焦入口也有同样反馈，触屏与减少动画模式不触发此动效。

## 本地运行

在项目目录执行 `python3 -m http.server 4178 --directory dist`，打开 http://localhost:4178。

规则检查：`node check-games.cjs`、`node check-drive.mjs`、`node check-arcade.mjs`、`node check-scene.mjs`。

`dist/` 即可直接部署的静态站点。游戏入口与界面逻辑在 `app.js`，2D 核心规则在 `game-core.js`；驾驶规则在 `drive-core.mjs`，驾驶渲染在 `games-3d.js`；新增两款游戏的规则在 `arcade-core.mjs`，渲染在 `arcade-3d.js`；岛岸和边界在 `island-world.mjs`，地形与海水在 `island-scene.js`；城市模型在 `city-models.js`，云层坐标在 `scene-motion.mjs`。

## 初版范围

全部游戏的成绩、收藏与外观通过当前浏览器 localStorage 保存。驾驶游戏为本站原创的同类玩法，未使用 Snow Rider 3D、Slope Run 或 Traffic Jam 3D 的游戏包、封面、品牌或接口。尚未接入自建账号、云存档、多人联网或跨设备排行榜。

旧版第三方嵌入因发行方返回 `unregistered=true` 拒绝本站域名，现已移除。Three.js 0.186.1 随站点托管，MIT 许可见 `dist/vendor/THREE-LICENSE.txt`。首次打开需加载本站资源，游戏运行不需要外部游戏服务。设备需支持 WebGL 2。

界面采用原创图形与排版，以克制的留白、半透明材质、圆角与柔和动效表达设计方向，与 Apple 无隶属关系。
